# Visual Fusion
Repository for the module#4 of ThinkAutonomous' 3D Computer Vision program: https://www.thinkautonomous.ai/courses

This project outlines a sensor fusion process that builds a depth map using LiDAR by projecting 3D point clouds onto a 2D image, detecting obstacles via the camera, and combining the results for object detection.
